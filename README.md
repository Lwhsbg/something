## Something
Demo : https://lwhsbg.itch.io/something
## What it is
It is a simple escape room inspired story that I brainstormed.
## Why I made it
I have always been fascinated by visual novels and wanted to try creating a small one by myself.
## How I made it
I used renpy for this and since this is my first project I did encounter many time consuming bugs which were very hard for me.
## What I learnt and what I struggled with
I had no prior knowledge of renpy before this project so it was fun learning as I went on, and the thing I struggled the most with was the backgrounds which were not showing up no matter what I did. At the end I managed to solve it somehow as there were double extensions.
